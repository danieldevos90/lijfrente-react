# Multi-Domain Content Strategy
## Zakelijke Financiering Platform - Domain Expansion Plan

### 🎯 **Executive Summary**

This document outlines the comprehensive strategy for deploying our zakelijke financiering platform across multiple domains, each targeting specific market segments with tailored content, SEO, and conversion strategies.

---

## 📊 **Domain Portfolio Strategy**

### **Primary Domains & Target Markets**

#### 1. **zakelijk-lening.nl** (Primary Domain)
- **Target**: General business financing (MKB)
- **Focus**: Broad market appeal, all business types
- **USP**: "De snelste zakelijke lening van Nederland"

#### 2. **werkkapitaal.nl**
- **Target**: Working capital financing
- **Focus**: Cash flow solutions, seasonal businesses
- **USP**: "Werkkapitaal binnen 24 uur geregeld"

#### 3. **ondernemersfinanciering.nl**
- **Target**: Entrepreneurs & startups
- **Focus**: Growth financing, innovation funding
- **USP**: "Financiering voor ambitieuze ondernemers"

#### 4. **bedrijfskrediet.nl**
- **Target**: Established businesses needing credit facilities
- **Focus**: Credit lines, revolving credit
- **USP**: "Flexibel bedrijfskrediet op maat"

#### 5. **mkb-financiering.nl**
- **Target**: SME market specifically
- **Focus**: Mid-market businesses, expansion capital
- **USP**: "MKB financiering zonder gedoe"

#### 6. **snelle-zakelijke-lening.nl**
- **Target**: Urgent financing needs
- **Focus**: Speed and efficiency
- **USP**: "Geld op je rekening in 24 uur"

## 🛠 **Technical Implementation**

### **Multi-Domain Architecture**

#### **Strapi CMS Configuration**
```javascript
// Site-specific content types
{
  "site": {
    "domain": "zakelijk-lening.nl",
    "brandColors": {
      "primary": "#000000",
      "secondary": "#ffffff"
    },
    "messaging": {
      "heroTitle": "Zakelijke financiering zonder gedoe",
      "heroSubtitle": "Van aanvraag tot uitbetaling in 24 uur",
      "primaryCTA": "Vraag je lening aan"
    }
  }
}
```

#### **Dynamic Content Loading**
```typescript
// Domain-based content switching
const getDomainContent = (domain: string) => {
  const domainConfig = {
    'zakelijk-lening.nl': zakelijkLeningContent,
    'werkkapitaal.nl': werkkapitaalContent,
    'ondernemersfinanciering.nl': ondernemersContent,
    // ... other domains
  };
  return domainConfig[domain] || defaultContent;
};
```

#### **Domain-Specific Sitemaps**
