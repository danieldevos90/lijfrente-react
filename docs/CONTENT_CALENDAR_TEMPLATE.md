## **SEO Content Guidelines**

### **Keyword Research Process**
```
1. Primary keyword identification (high volume, medium competition)
2. Long-tail keyword mapping (specific to domain focus)
3. Competitor keyword analysis
4. Search intent analysis
5. Content gap identification
```

### **On-Page SEO Checklist**
```
□ Target keyword in title (within first 60 characters)
□ Meta description with keyword (150-160 characters)
□ H1 tag with primary keyword
□ H2/H3 tags with secondary keywords
□ Keyword density 1-2% (natural usage)
□ Internal links to relevant pages (3-5 per post)
□ External links to authoritative sources (1-2 per post)
□ Image alt text with keywords
□ URL slug with target keyword
□ Schema markup implementation
```

### **Content Quality Standards**
```
- Minimum 800 words for blog posts
- Maximum 2000 words (unless comprehensive guide)
- Readability score: 60+ (Flesch Reading Ease)
- Unique value proposition in each piece
- Actionable advice and practical tips
- Data/statistics to support claims
- Regular updates to maintain freshness
```
