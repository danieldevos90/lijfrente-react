# Stitch Prompt: Homepage - Initial State

## Screen Overview
Landing page for a multi-site business financing platform. Clean, minimal design with centered content and a primary CTA.

## Design System

### Colors
- Brand Primary: `#000000` (Black)
- Brand Dark: `#1a1a1a`
- Text Primary: `#0F172A` (Dark slate)
- Text Muted: `#64748B` (Slate gray)
- Background: `#FFFFFF` (White)
- Border: `#E2E8F0` (Light gray)

### Typography
- Font: Inter, system-ui, -apple-system, Segoe UI
- H1: 48px, weight 700, line-height 1.1
- Body: 20px, line-height 1.6

### Spacing & Layout
- Container max-width: 1200px
- Horizontal padding: 24px
- Border radius (buttons): 10px

## Layout Structure

### Full Page
- Min-height: 100vh
- Background: White
- Centered content (vertical & horizontal)

### Hero Section
- Centered text alignment
- Vertical padding: 4rem (64px)

### Content Elements

**Heading (H1)**
- Text: "Welkom"
- Font size: 48px
- Font weight: 700 (Bold)
- Color: `#0F172A`
- Margin bottom: 1.5rem (24px)

**Subtitle (Paragraph)**
- Text: "Dit is een minimale multi‑site frontend met design tokens en Strapi integratie."
- Font size: 20px
- Color: `#64748B` (muted)
- Max-width: 600px
- Margin: 0 auto 2rem
- Line-height: 1.6

**Primary CTA Button**
- Text: "Bekijk demo‑site"
- Background: `#000000` (Black)
- Text color: `#FFFFFF` (White)
- Padding: 16px 32px
- Border radius: 10px
- Font size: 18px
- Font weight: 600
- Box shadow: `0 2px 8px rgba(0,0,0,0.2)`
- Margin top: 2rem (32px)

**Button Hover State**
- Background: `#1a1a1a`
- Transform: translateY(-2px)
- Box shadow: `0 6px 20px rgba(0,0,0,0.3)`
- Transition: all 0.2s ease

## Spacing Hierarchy
- Top to H1: Auto (centered)
- H1 to Subtitle: 24px
- Subtitle to Button: 32px
- Button to bottom: Auto (centered)

## Notes for Stitch
- Center all content both vertically and horizontally
- Use flexbox for centering
- Keep design minimal and clean
- Ensure adequate whitespace around all elements
- Button should have clear clickable appearance with shadow
